# GIOP fits — LOC1 / FLENS8 (8 deg)

Everything about the inversion for this site. Generated by

    python make_giop_figures.py <this location folder>

which reads `../FINAL_Rrs.csv` (the amplitude-normalised mean) and the scans themselves.

Uses **our** port, `tmittal22/giop-workbench`, not upstream MATLAB: the bounded solver,
the per-band sigma and the `fit_shapes` guard are all additions.

## Two things are fitted here

**1. The mean shape** (`../FINAL_Rrs.csv`), hyperspectral 400-700 nm, n=301:

| | value | +/- (from the 1.7 % shape uncertainty) |
|---|---|---|
| M_phi | 11.47 | 2.2 % |
| a_dg(443) | 1.254 m^-1 | 1.7 % |
| b_bp(443) | 0.0836 m^-1 | 1.1 % |

**2. Each scan separately**, using its own angle-matched sky (`giop6`, 12 pairs):

| | mean across scans | sd |
|---|---|---|
| M_phi | 11.45 | 13 % |
| a_dg(443) | 1.254 | 8 % |
| b_bp(443) | 0.0847 | 11 % |

The two agree to **0.2 %** on every parameter, which is a real consistency check: fitting
the mean and averaging the fits are different operations on a nonlinear inversion and
there was no guarantee they would land together. The per-scan sd (8-13 %) tracks the 11 %
amplitude spread, as it should — the scans are the same water at different concentrations.

## What to quote

- **a_dg(443) = 1.25 +/- 0.10 m^-1** and **b_bp(443) = 0.085 +/- 0.009 m^-1**, using the
  scan-to-scan sd, which is real variability rather than fit error.
- **Not chlorophyll.** M_phi = 11.5 is precise (2 %) but that is precision, not accuracy:
  the model still misfits by 10.7 % RMS hyperspectral, and sweeping S_dg over 0.014-0.022
  moves it 2.4 -> 20.9. A Case-1 aph* on Case-2 water does not become right by being
  well-conditioned.
- **u(lambda)**, in `../REPORT.txt`, needs no library at all.

Full argument, including the correction where this was first run on 6 bands and the
conditioning reported as GIOP's limit: `LOC1_GIOP_FINDINGS.md` at the repository root.
